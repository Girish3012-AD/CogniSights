* System Workflow
**SIH26094 - AI Powered Dynamic Mental Health Monitoring and Distress Prediction System
  
** Overview
The proposed system works by collecting user emotional and behavioral data, analyzing the patterns using Artificial Intelligence and Machine Learning techniques, and predicting possible mental distress levels.

*Detailed Workflow

* 1. User Data Collection

The system collects different types of user information:

- Daily mood input
- Journal or text-based feelings
- Stress-related responses
- Sleep patterns
- Activity information

The collected data helps the system understand the user's emotional state.

**2. Data Preprocessing
Raw user data is converted into a format suitable for AI models.
Operations include:
- Removing unnecessary data
- Cleaning text data
- Handling missing values
- Data transformation

** 3. Natural Language Processing (NLP)
NLP techniques analyze user text input.
The system identifies:
- Positive emotions
- Negative emotions
- Stress-related words
- Emotional changes
Example:
Input:
"I feel exhausted and unable to focus on my studies."
Output:
Detected emotion:
Stress / Anxiety

**4. Feature Extraction
Important patterns are extracted from user data:
- Sentiment score
- Emotional frequency
- Mood changes
- Stress indicators

**5. Machine Learning Prediction
The extracted features are given to ML models.
The model predicts:
- Low Risk
- Medium Risk
- High Risk
Example:
Mental Distress Level:
Medium Risk (65%)

**6. Personalized Recommendation System
Based on prediction results, the system provides suggestions:
- Relaxation activities
- Meditation exercises
- Stress management techniques
- Professional support recommendation

 **7. Continuous Monitoring
The system continuously tracks changes in emotional patterns and provides early warnings when negative patterns increase.

** Final Output
The user receives:
- Mental wellness score
- Stress level prediction
- Emotional trend analysis
- Personalized suggestions
